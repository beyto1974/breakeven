# Security policy

Break-even is a static site: no server, no accounts, and nothing is stored. All state lives in the URL.

## Reporting a vulnerability

Please report vulnerabilities privately through **Security → Report a vulnerability** on this repository (GitHub private vulnerability reporting). Do not open a public issue.

Include the affected URL or file, steps to reproduce, and the impact you see. Expect a first answer within a week.

## Scope

- The site published on GitHub Pages and the code in this repository.
- `src/server` is a local preview server for development and tests. It is not deployed.
