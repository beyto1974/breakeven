What was built, and what the reviews found

A stateless rentability report hosted on GitHub Pages. Every setting lives in the URL, the interface is available in English, Dutch and French, and a target solver runs the model backwards.

Delivered

Features

  • Projection engine: customers, growth, churn, units, price and subscription (both VAT included), variable, fixed and acquisition cost. Money is held in integer cents. Outputs are the break-even threshold, break-even month, payback month, margin and margin rate.
  • Report: a one-sentence answer with a verdict, four headline figures, a month-by-month chart with a hover readout, a 7 × 7 price × usage grid (click a cell to apply it) and a monthly table. The per customer per month field shows the average revenue and contribution per customer.
  • Target solver: choose break-even by month M, payback by month M, or a total margin. Then choose one of nine assumptions, and the solver finds the value that just meets the goal. One click applies it.
  • Languages: en, nl and fr, set by lang or detected from the browser and then written to the URL. Number format, nouns and title follow the language. Plural rules cover regular words, and customerPlural and unitPlural handle irregular ones.
  • Sharing: the URL contains only the values that differ from the defaults. Copy-link, JSON and CSV downloads are built in the browser.
  • Hosting: a GitHub Actions workflow runs the tests, builds with the Pages base path and deploys.
